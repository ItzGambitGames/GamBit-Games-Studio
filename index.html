1. Host Free on Web

Publish your game hub online for free so anyone can play from a browser url.

  • GitHub Pages: Push this HTML file to a GitHub repo and enable Pages.
  • Vercel / Netlify: Drag and drop your project folder directly onto their web upload panel.
  • Itch.io: Zip this file and upload as an HTML game launcher project.

2. Convert to Mobile App (APK / iOS)

Turn this web hub into a native mobile app package for Google Play Store or Apple App Store.

  • PWABuilder: Enter your hosted website URL into PWABuilder.com to generate an Android APK / Meta / iOS PWA package.
  • Capacitor JS: Run npx cap init in your folder to generate native Android Studio and Xcode projects!
  • Website2APK / Cordova: Wrap this single HTML file into an offline Android app bundle (.AAB).

How to Bundle Games Permanently into the Code

If you want your players to see your custom games automatically when they open your published app, copy your exported JSON library data into the DEFAULT_GAMES JavaScript array inside this HTML file before building!
